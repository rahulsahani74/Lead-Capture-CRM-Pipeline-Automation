Developer setup (remove this block in production)
  1. Import and activate 01_lead_capture_crm.json in n8n.
  2. Open the Webhook node and copy the Production URL (or the Test URL while the workflow is open and listening).
  3. Edit WEBHOOK_URL in the script at the bottom of this file.
  4. http://localhost:5678/... only works from this computer. Visitors on the internet cannot reach it; for real traffic you need a public HTTPS URL (reverse proxy, tunnel, or a hosted n8n). Never put API keys or secrets in this page; anything here is visible to every visitor.
